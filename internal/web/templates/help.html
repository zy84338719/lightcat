{{icon "monitor"}}{{T "这是什么"}}

{{T "LightCat 是光猫（ONU）的纳管与运维面板：它实现 TR-069 / CWMP 协议，让光猫主动上报参数与任务结果，把散落在各处的「设备信息、无线终端、光功率、固件升级、告警」收进一个界面。"}}

{{T "支持两条接入通道：有运营商超管时走标准 CWMP；没有超管时，用光猫的普通账号经 Web 适配通道（ontweb）纳管，同样只读、不改设备配置。"}}

{{icon "zap"}}{{T "第一次接入设备"}}

  1. {{T "确认本服务已经启动"}}
    {{T "启动后终端会打印 ACS 的监听地址（默认 :7547）与面板地址。面板首页现在应该还没有设备，这是正常的。"}}
  2. {{T "把光猫的 ACS URL 指向本服务"}}
    {{T "在光猫的 TR-069 配置里把 ACS URL 填成"}} {{.ACSPath}} {{T "（或根路径"}}/{{T "）。ACS URL 末尾的 IP 必须是光猫能访问到的地址，"}} {{T "不要填 127.0.0.1 —— 那是光猫自己，不是你的面板。"}}
  3. {{T "等设备主动 Inform"}}
    {{T "设备上线后会自动上报。周期通常是几分钟到一天不等（取决于设备配置），也可以在设备详情页点「采集」主动催一次。"}} {{T "上报后设备就会出现在「设备列表」里。"}}
  4. {{T "没有超管账号？用 Web 适配通道"}}
    {{T "普通账号也能纳管：跑一次一次性采集，或配 -ontweb-* 让服务端定时采。"}} lightcat ontweb -url http://192.168.1.1

{{icon "list"}}{{T "页面怎么用"}}

{{T "设备列表"}} — {{T "日常运维的主页面：在线状态、光功率、参数数一目了然。点表头可排序，搜索框支持序列号 / 备注 / 名称 / SSID。"}}
{{T "清单"}} — {{T "资产盘点视角：不筛选、不裁列，历史上纳管过的设备都在，连低频字段（WAN 口 IP、首次纳管时间）也列出来。"}}
{{T "告警"}} — {{T "收光过低、光模块过温、光口异常、设备离线的记录，配了 webhook 还会额外推送一份。"}}
{{T "预设"}} — {{T "「事件 + 条件命中时自动下发参数」：比如设备重连后自动把 5G 名字改回来。"}}
{{T "固件"}} — {{T "上传固件/配置文件并下发到设备；设备自己来拉 URL，支持批量错峰。"}}
{{T "设置"}} — {{T "监听端口、面板账号密码、API Token；还能一键下载 Prometheus 抓取配置与 Grafana 看板。"}}

{{icon "info"}}{{T "常见问题"}}

{{T "设备没出现在列表里？"}}
{{T "先确认光猫的 ACS URL 指向的是面板所在机器的可达地址（不是 127.0.0.1）；再看 ACS 侧有没有收到 Inform —— 面板开着自动刷新时状态会自己变。"}}

{{T "收光显示「-」？"}}
{{T "这一台还没采到光功率。点设备详情页的「采集」下发一次读取任务，设备下次 Inform 时结果会回来。不同厂商的参数路径差异很大，认不出来时可以在「设置」里配映射表。"}}

{{T "忘了面板密码？"}}
{{T "用环境变量 ACS_WEB_AUTH=off 起一次就能进去（救急用），进去后在「设置」里改完密码再关掉。"}}

{{T "想让 Prometheus 抓数据？"}}
{{T "在「设置」页配一个 API Token（至少 16 位），然后下载 Prometheus 抓取配置，它已经带上了可达地址与 Bearer token，并进 prometheus.yml 即可。Grafana 看板也可以在同页下载，导入后数据源选你自己的 Prometheus。"}}
